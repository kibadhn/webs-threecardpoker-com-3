## 游戏规则简述

1. 每局开始，每位玩家获得三张牌。
2. 玩家根据牌面大小决定是否加注、跟注或弃牌。
3. 牌型从大到小依次为：豹子 > 同花顺 > 同花 > 顺子 > 对子 > 散牌。
4. 最终剩余玩家比较牌面，牌大者赢得底池。

详细规则可在游戏内查看帮助说明。
